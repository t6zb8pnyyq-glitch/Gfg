# UNIVERSE CREATOR MASTER SPECIFICATION

## Overview
The Universe Creator is a browser-based, pure-vanilla-JS computational physics laboratory. It requires strict mathematical modeling of multi-scale physics (N-body gravity, SPH fluid dynamics, thermonuclear reaction networks, relativity proxies) integrated into a canonical simulation state.

## Core Directives
1. **No Fake Physics**: Every numerical model must derive from a scientifically defensible mathematical model. Zero visual heuristics or "snapping".
2. **Modular Architecture**: The codebase must be separated into domains: `core`, `math`, `physics`, `render`, `ui`, `data`.
3. **Canonical State**: All objects use a unified `PhysicalBody` format.
4. **Validation Driven**: Features are incomplete unless validated by automated scientific checks in the UI.

## Initial Audit Findings
- The codebase was entirely generated by a Python script (`generate_html.py`), dumping massive string literals into a single HTML file.
- We have now established a `src/` directory. The next step is to parse the monolithic JS out of `generate_html.py` into appropriate modules, construct a real `build.py` orchestrator, and verify that the build succeeds without losing functionality.
